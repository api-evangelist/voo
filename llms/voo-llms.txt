# VOO (now SideUp)

> VOO was an Egyptian logistics marketplace that rebranded as SideUp in December 2022, relocating its headquarters from Egypt to Riyadh, Saudi Arabia. SideUp is a fully integrated courier marketplace that lets e-commerce businesses ship locally and globally from one dashboard — connecting merchants with multiple courier services, plus payment gateways, shipping API integration, warehousing, and fulfillment. Backed by 500 Global, Launch Africa VC, Riyadh Angels, and Alex Angels ($1.2M seed, December 2022).

SideUp publishes no public developer portal, API reference, or machine-readable API specs as of July 2026. Its "shipping API integration" is offered to merchants through its platform and e-commerce plugins (Shopify, Salla, OpenCart) rather than as an open API program.
